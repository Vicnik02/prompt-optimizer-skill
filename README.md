# Prompt Optimizer — 提示词优化器（AI Skill）

一个可直接安装到 AI 编程助手 / Agent 中的 **skill 提示词优化器**：把草稿级的 prompt 优化为高质量提示词，一次生成 **A/B/C/D 四种策略变体** 供你对比选择，大幅降低提示词门槛。

## 它能做什么

| 策略 | 思路 | 适合场景 |
|------|------|----------|
| **A 详细展开式** | 补充上下文、约束、边界、输出格式、成功标准 | 需要确定性输出的任务 |
| **B 角色扮演式** | 专家人设 + 思维链引导 + 方法论 | 深度分析、创意生成 |
| **C 结构化式** | 拆解为 3~7 个子步骤，每步可验证 | 复杂多步骤任务 |
| **D 逆向提炼式** | 从模糊需求反推真实目标 | 需求不明确、探索性任务 |

**使用方式**：对 AI 说「优化这个 prompt：……」，它会先复述理解、必要时追问关键信息，再输出四种优化版本和快速对比表。

## 安装

把 `prompt-optimizer/` 目录复制到你所用 AI 工具的 skills 目录即可，例如：

```
# Claude Code / ZCode 等基于 SKILL.md 规范的工具
~/.agents/skills/prompt-optimizer/
```

安装后，当你表达「优化 / 改进 / 润色 prompt，让指令更清晰」的意图时，它会自动触发。

## 仓库结构

```
├── prompt-optimizer/
│   └── SKILL.md        skill 本体（核心，即装即用）
└── index.html          项目展示页（GitHub Pages）
```

## 使用技巧

- **信息缺失时它会追问**：原 prompt 缺目标受众 / 输出格式 / 约束条件时，先答 1~2 个关键问题比硬猜效果好
- **可以混合策略**：四种版本都不完全满意时，可以要求「A 的细节 + C 的结构」组合
- **保持语言一致**：中文输入输出中文，英文输入输出英文
